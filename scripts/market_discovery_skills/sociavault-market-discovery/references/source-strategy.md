# 发现研究的来源选择

新市场发现先通过真实趋势接口取得线索并建立候选池，再用社区求助、使用经历、现有商品等解释需求和反证。LLM 自主决定如何聚类和筛选，不能先自选品类再把关键词搜索包装成趋势发现。

Google Trends 通过 SellerSprite 的 `google_trend` 获取，系统前缀形式为 `sellersprite__google_trend`；先读取当前 tools/list 的实际 schema，不假设参数或嵌套结构。SociaVault 用于 TikTok 趋势及后续社媒取证，不把其 Google Search/SERP 当作 Google Trends。工具未提供或不在当前权限范围时明确限制，不伪造调用，不为此修改官方预设白名单。

区别“取得未知候选的趋势榜单”与“验证给定关键词走势”。如果 `google_trend` 需要关键词，先从可用的真实趋势列表取得种子，再调用它验证走势，不先凭空列品类。榜单、上升查询、相关趋势或已保存且可追溯的趋势线索可作为种子；普通关键词搜索不替代候选发现。TikTok 普通关键词搜索适合后续取证，某一个 trending feed 的效果也不能代表全部行业标签趋势接口。最终工具名、参数和能力以实时 schema 为准。

保存候选对应的趋势记录和原始响应位置。趋势兴趣或热度不直接证明市场规模与付费需求；从事件、标签或主题映射到消费类目需要说明联系并验证，不能仅靠联想创造新候选。遇到接口不可用时尝试其他已确认的趋势入口，并明确覆盖限制；全部不可用就保留阻塞，不声称候选来自趋势。

先看当前 SociaVault 工具目录。类目、场景或人群已经明确且值得继续调查时，默认先做跨平台广泛检索，再集中深入有价值的线索。将类目别名、用户说法、用途和替代方案用于发现不同语境，不只搜商品标准名。覆盖所有与该对象相关且可访问的平台；不因熟悉 Reddit/TikTok 就跳过其他入口。明显无关或不可用的平台可以跳过，留下简短理由；不设相同样本数、固定调用顺序或平台评分。已有决定性证据足以淘汰或交接时，可行性模块仍可提前结束该方向，不为覆盖而耗尽预算。

当前固定工具集提供以下研究入口，实际名称和参数仍以 tools 为准：

| 平台 | 找线索与深入方式 |
| --- | --- |
| YouTube | 关键词搜索；视频详情、转录、评论及回复，适合实际使用和长期体验材料 |
| X / Twitter | twitter_search 搜索原帖；tweet 详情、评论、引用及视频转录 |
| Facebook | 公开群组帖子、主页帖子/reels、帖子详情、评论及转录；Meta 广告搜索单独标为供给/广告材料 |
| Instagram | 定位账号或帖子后取 posts/reels、详情、评论和转录 |
| Threads | 关键词搜索、帖子详情和用户帖子 |
| Pinterest | 关键词搜索与 pin 详情；收藏与视觉表达不直接证明购买需求 |
| TikTok / Shop | 关键词/标签及趋势入口；视频、评论、商品详情与购买评价 |
| Reddit | 全站或相关社区搜索，再读具体帖子评论；结果偏题时不要继续按同样参数泛搜 |

Facebook 和 Instagram 在当前固定版本中没有通用帖子关键词搜索。可使用已有品牌/社区线索或 google_search 的站点限定查询定位公开 URL，再调用对应内容接口；没有可访问目标时记录覆盖缺口。广告库关键词搜索不能冒充消费者帖子搜索。各平台的角色只是线索，不预设哪个平台一定代表哪类需求。

从需要观察的材料选择入口：使用过程可能在短视频、图文展示或教程中；失败经历、替代办法与购买阻力可能在评论、回复、讨论串或商品评价中；偏好变化可能表现为搭配、收藏、分享或实际采用。哪个平台更可能出现这些材料，由具体人群和问题决定，不将“痛点”固定映射到 Reddit，或将“趋势”固定映射到 TikTok。商业内容可解释供给与卖点，不能自动充当独立用户需求。

当前后端暴露的工具只是 SociaVault 全部能力的一个子集。区分“供应商支持某平台”与“本轮可调用”；只使用实际目录中的能力，缺失时记录覆盖限制，不编造工具或擅自扩大权限。必要时用可用搜索定位原始来源，搜索排名和摘要本身不证明需求量。

查询围绕一个具体疑问展开，避免把所有场景、功能和评价词堆入同一次搜索。返回偏题、重复或只有宣传时，判断是查询、来源还是假设不合适，再自主缩词、换表达、换来源、深入已有相关材料或放弃该方向。不要把一次泛搜无效当作已验证需求不存在；也不为完成调用数重复无效查询。

在类目记录中简记本轮实际覆盖的来源、发现或缺口，让下一步知道哪里已查、哪里值得深入。需要重看结果时读取已保存 call_id；同轮同参数重查应有明确刷新或故障恢复理由，不为处理大响应重新付费。摘要保留内容、作者、实际日期、链接和相关指标，原始响应留存；跨平台转载、同一广告活动和同一作者不算独立证据。

线索值得投入时，再选择详情、评论、回复、转录或独立来源。评论中的新问题可以产生下一分支；反证也可以使当前分支结束。工具实时名称和参数以当前schema为准，不凭记忆拼工具名称。
