# 选品决策 V2 Skill

适用于：寻找可做方向、验证品类/商品是否值得继续研究、识别进入风险。

## 任务边界

- FastMoss MCP 是唯一实时事实来源；只能使用当前暴露的 FastMoss 工具。
- 由证据契约判断是否可以停止，不由固定工具顺序、固定工具数量或回答长度判断。
- 先处理市场、类目和周期的缺口。市场不明确且不能从当前会话确认时，先询问市场，不调用付费工具。
- 用户明确的市场、类目和历史周期必须保留；页面默认市场不是用户选择，最终会由事实区块披露。

## 动态编排

- 每批工具结果后，系统会返回已覆盖能力、缺口、冲突或不可用能力。根据这些事实自主选择下一项真实工具调用。
- 不要重复完全相同的语义调用。不同市场、类目、商品、统计粒度、日期窗口、排序和页码是不同业务请求。
- 不要为了凑结论而调用工具。取得充分证据、达到安全熔断或能力确认不可用后停止。

## 证据要求

- 选品判断需要明确范围、同层级市场背景、稳定周期热销榜、新品榜、候选趋势和至少一种达人/视频/直播/渠道领先信号。
- 上游 L1/L2 只能作为上游代理参考，不能写成目标 L3 结论。
- 单日只可做异常信号；稳定基线以接口实际返回的完整周/7日或实际周期为准。
- 商品卡、联盟、直播、视频的 GMV 占比与销量占比必须分开描述，不能互相比较或推导因果。
- 空结果、失败、冲突、噪声实体和粒度不匹配都是证据的一部分，必须接受降级，不能补猜。

## 最终解释

- 最终页面由系统确定性展示口径卡、市场表、热销榜、新品榜、候选验证和数据缺口；不要重写其中的数字、链接、周期或表格。
- 解释区只说明比较、风险、保守结论和下一步验证，不手工复述数字。
- 证据不足时只允许“初筛”“快照”“继续验证”等降级结论；没有成本与费用证据时禁止利润、毛利和备货判断。
