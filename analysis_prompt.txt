# TK带货脚本识别解析系统（优化版）

## 任务目标

拿到 TikTok 带货视频 `.analysis.json` 后，不要复述视频，而要判断：

```text
它是哪类脚本？
它服务哪个漏斗阶段？
它靠什么让人停留？
它靠什么让人相信？
它靠什么让人想买？
它哪里不行？
它适合复制到什么产品？
下一条素材应该怎么改写？
```

最终输出必须让操盘手、编导、剪辑、投手都能直接使用。

## 读取优先级

优先读取：

1. `transcript.text`：文案、话术、卖点顺序、CTA。
2. 顶层 `timeline`：时间线、镜头、字幕、产品露出。
3. 顶层 `visual_evidence`：画面证据、人物动作、产品细节。
4. `summary`：只做辅助参考，可能被截断或格式不稳定。

要求：

- 关键判断必须尽量绑定 transcript、timeline 或 visual_evidence 中的证据。
- 如果没有观察到证据，必须写“未观察到”，不能脑补。
- 不要把 summary 当成唯一依据。

## 分析顺序

必须按照以下顺序分析：

1. 先判断主脚本类型。
2. 再判断漏斗阶段。
3. 再找核心驱动力：停留 / 信任 / 成交。
4. 再拆时间线结构。
5. 再判断卖点是否被画面证明。
6. 再做负面锐评。
7. 最后输出复刻建议和改写方向。

禁止先套模板再找证据。

## 漏斗阶段判断

### 顶部漏斗 TOF

目标：让陌生用户停留、看完、评论、产生兴趣。

常见信号：

- 故事、反差、梗、街访、奇怪问题。
- 产品不一定一开始出现。
- 重点是好奇心、情绪、原生感、评论话题。

判断：

```text
不买东西的人会不会也愿意看？
用户为什么会停留？
评论区可能聊什么？
```

### 中部漏斗 MOF

目标：说服已有需求的人，解决购买犹豫。

常见信号：

- 明确产品和场景。
- 展示卖点、上身、实测、对比。
- 解决尺码、效果、舒适度、耐用性、适配人群。

判断：

```text
它解决了哪个购买顾虑？
它证明了什么，而不是只说了什么？
```

### 底部漏斗 BOF

目标：推动立即下单。

常见信号：

- 限时优惠、库存稀缺、套装折扣。
- 价格对比、社会证明、强 CTA。

判断：

```text
它给了用户现在买的理由吗？
优惠是否有参考系？
```

## 脚本类型库

一条视频可以有主类型和辅助类型。

### 1. 故事型带货

先讲人物、冲突、尴尬、失败、转折，产品后置出现。

适合：情绪价值产品、礼品、家居小物、美妆个护、宠物用品。

重点看：故事冲突是否快，产品是否自然成为解决方案。

### 2. 痛点型带货

直接戳用户问题，再给产品解决方案。

适合：个护、清洁、收纳、健康、工具、母婴、宠物。

重点看：痛点是否具体，有没有过程证明或前后对比。

### 3. 测评/实测型带货

用测试、实验、挑战、前后变化证明产品。

适合：美妆、清洁剂、工具、防水防摔、健身器材、功能服饰。

重点看：测试是否可信，过程是否一眼能懂。

### 4. 场景型带货

把产品放进厨房、浴室、通勤、办公室、宿舍、车内等真实场景。

适合：家居、厨房、收纳、旅行、办公、服饰配件。

重点看：场景是否真实，用户能否代入。

### 5. 价格优惠型带货

用参考系让用户觉得划算。

常见：Don't buy this unless... / Five for the price of one。

适合：服饰、日用品、套装、季节品、节日促销品。

重点看：是否有原价、竞品、渠道、套装数量对比。

### 6. 反常识/知识型带货

先打破认知，再引出产品。

常见：You've been using this wrong / What nobody tells you about...

适合：健康、美妆、健身、工具、个护、厨房。

重点看：反常识是否和产品强相关。

### 7. 视觉隐喻型带货

用具体物体表达抽象功效。

例子：草莓模拟草莓鼻，面包/菠萝模拟粗糙毛孔，污水模拟身体垃圾。

适合：美妆、清洁、保健品、护肤、功效抽象的产品。

重点看：隐喻是否一眼能懂。

### 8. 达人原生种草型

像真实分享，不像广告。

常见：I randomly tried this / I use this every day now。

适合：美妆、服饰、小家电、包包配饰、生活好物。

重点看：口语感、生活痕迹、产品出现是否自然。

### 9. 强转化口播型

直接讲卖点、利益点、价格和 CTA。

适合：已有需求人群、促销期、低客单、功能明确产品。

重点看：信息密度、卖点排序、CTA 是否有购买理由支撑。

### 10. 评论回复/社证型带货

用评论、反馈、销量、问答建立信任。

常见：Replying to... / Someone asked if this works。

适合：需要信任的产品、效果型产品、服饰尺码类产品。

重点看：评论是否真实，是否解决关键顾虑。

### 11. 街访/情景采访型带货

用随机采访、路人反应、问答制造原生感。

常见：What's in your bag? / Why do you have this?

适合：包包配饰、服饰、鞋帽、可爱小物、校园/通勤产品。

重点看：问题是否自然，产品是否通过回答出现。

### 12. 角色设定/拟人化型带货

给产品一个身份，而不是只讲功能。

例子：emotional support critic / tiny therapist / desk guardian。

适合：毛绒玩具、包挂、解压玩具、小夜灯、香薰、桌面摆件。

重点看：身份是否有梗，是否容易被评论和记住。

### 13. 对比替代型带货

用旧方案、竞品、传统渠道对比新方案。

常见：Stop buying X when Y does the same thing。

适合：平替、工具、清洁、个护、家居、服饰。

重点看：新方案是否证明省钱、省事、省空间、省时间。

### 14. 过程解压/视觉奇观型带货

靠动作过程本身留人。

常见动作：倒水、拉扯、书写、切割、清洁、挤压、组装、开箱、变色。

适合：清洁用品、工具、杯子、收纳、玩具、美妆、厨房。

重点看：动作是否有完成欲，是否有前后变化。

### 15. 教程/方法型带货

先教方法，产品作为方法的一环出现。

适合：工具、美妆、健身、厨房、摄影、学习办公。

重点看：教程是否真的有用，产品是否自然必要。

## Hook 识别

重点看前 0-3 秒。

常见 hook：

- 奇怪提问：为什么你的包里有这个？
- 负面钩子：不要买，除非...
- 反常识：你一直用错了
- 故事冲突：前妻拿走了一切
- 结果悬念：用了 7 天后发生了什么
- 动态动作：写字、倒水、拉扯、拆装
- 评论回复：有人问这个是否有效
- 价格刺激：一条的钱买五条
- 身份设定：这是我的情绪支持评论员

判断：

```text
强 hook = 3 秒内制造未知、反差、动作、情绪或利益点。
弱 hook = 直接说产品很好、功能很多、价格很低，但没有停留理由。
```

## 卖点视觉化检查

不要只记录“说了什么卖点”，要看卖点有没有被画面证明。

常见映射：

- 弹性：拉扯。
- 防水：倒水。
- 清洁力：污渍前后对比。
- 舒适：上身动作、坐下、跑跳。
- 尺码：身高体重参考、尺码表。
- 容量：装入多个物品。
- 便携：放入口袋/包里。
- 情绪价值：表情、拥抱、随身带。
- 价格优势：数量展示、渠道对比、原价对比。

## 用户心理拆解

每条视频至少判断：

```text
停留：为什么不划走？
理解：用户是否知道这是什么？
兴趣：它和用户有什么关系？
信任：凭什么相信？
顾虑：解决了哪个犹豫？
行动：为什么现在买？
传播：用户会评论或转发什么？
```

## 成交强度评分

每条视频必须给出成交强度评分，1-5 分。

```text
1 分：只有内容吸引，没有产品理解。
2 分：知道产品，但没有信任证明。
3 分：有卖点和场景，但缺少立即购买理由。
4 分：有信任证明和明确 CTA。
5 分：有强痛点、强证明、强优惠或强稀缺。
```

评分时必须说明：

- 成交强在哪里。
- 成交弱在哪里。
- 是否适合直接投转化。

## 复刻风险等级

每条视频必须判断复刻风险。

```text
低：主要靠结构、卖点、场景，可换产品复制。
中：依赖一定演员表现、剪辑节奏或产品视觉效果。
高：依赖路人反应、强人设、特殊剧情、极端价格或偶然性。
```

要求：

- 不能只写风险等级。
- 必须说明为什么会翻车。
- 必须说明换产品复制时要保留什么、替换什么。

## 负面锐评检查

每条视频必须给负面评价，不能只夸。

检查维度：

- 开头风险：前 1 秒是否看不懂、太慢、太绕、没有视觉锚点。
- 产品理解风险：用户是否知道卖的是什么，是否只记住梗不记得商品。
- 信任风险：有没有实测、对比、评论、细节近景。
- 转化风险：有没有购买理由、价格参考系、顾虑处理、CTA。
- 受众错配风险：是否太小众、太依赖语言梗或特定人群。
- 复刻风险：是否依赖演员、运气、路人反应，换产品后是否成立。
- 平台表现风险：节奏是否慢，镜头是否单一，信息密度是否不足。

默认输出：

```text
负面锐评：
- 最大问题：
- 可能划走点：
- 可能不转化点：
- 信任不足点：
- 复刻翻车点：
- 不适合的产品/人群：
```

## 输出格式规范

每次解析必须按以下结构输出。不要只写结论，必须给判断依据。

### 1. 操盘手快速结论

```text
视频一句话定位：

主脚本类型：

辅助脚本类型：

漏斗阶段：

核心逻辑：
- 靠什么让人停留：
- 靠什么让人相信：
- 靠什么让人想买：

成交强度评分：X/5

复刻风险等级：低 / 中 / 高

最大问题：
```

要求：

- 视频一句话定位必须说明“它本质上在卖什么”和“靠什么吸引人”。
- 主脚本类型只能选 1 个。
- 辅助脚本类型可选 1-3 个。
- 漏斗阶段必须说明判断理由。
- 最大问题必须具体，不允许写“内容还可以优化”。

### 2. 证据引用

```text
关键证据：
- 文案证据：
- 画面证据：
- 时间线证据：
- CTA/优惠证据：
```

要求：

- 如果判断为痛点型，必须指出哪句文案或哪个画面体现痛点。
- 如果判断为实测型，必须指出具体测试动作。
- 如果判断为 BOF，必须指出具体价格、优惠、CTA 或稀缺信息。
- 如果没有证据，必须写“未观察到”。

### 3. 时间线结构拆解

按时间段拆解：

```text
0-3 秒：
- 画面：
- 文案/字幕/口播：
- 作用：
- 风险：

3-8 秒：
- 画面：
- 文案/字幕/口播：
- 作用：
- 风险：

8-15 秒：
- 画面：
- 文案/字幕/口播：
- 作用：
- 风险：

15 秒以后：
- 画面：
- 文案/字幕/口播：
- 作用：
- 风险：
```

如果视频较短，可以合并时间段，但必须保留“画面 / 文案 / 作用 / 风险”四项。

### 4. Hook 分析

```text
Hook 类型：

Hook 强度：强 / 中 / 弱

判断依据：

可能划走点：
```

要求：

- 必须说明前 0-3 秒具体靠什么制造停留。
- 必须指出用户可能在哪一秒失去兴趣。

### 5. 流量逻辑 / 信任逻辑 / 成交逻辑

```text
流量逻辑：
这条视频为什么有人愿意看？

信任逻辑：
这条视频凭什么让人相信？

成交逻辑：
这条视频凭什么让人现在买？
```

要求：

- 如果某一项缺失，必须明确写“该视频的 XX 逻辑较弱，主要问题是……”。
- 不能把流量逻辑误判成成交逻辑。
- 如果没有强成交逻辑，要明确说它只适合顶部漏斗或种草。

### 6. 卖点呈现与视觉证据

按表格输出：

| 卖点 | 是否被画面证明 | 画面证据 | 可信度 | 问题 |
|---|---|---|---|---|
|  |  |  |  |  |

要求：

- 不能只写“舒适、好看、便宜”。
- 必须说明卖点是“说出来的”还是“拍出来的”。
- 如果没有视觉证据，要明确标注“只靠口播，信任不足”。

### 7. 用户心理拆解

```text
停留：
用户为什么不划走？

理解：
用户是否能快速知道这是什么产品？

兴趣：
它和用户自身需求有什么关系？

信任：
用户凭什么相信这个产品有效？

顾虑：
它解决了哪个购买犹豫？还有哪个顾虑没解决？

行动：
用户为什么现在下单？如果没有理由，要明确指出。

传播：
用户可能评论、转发、@朋友的点是什么？
```

### 8. 负面锐评

必须输出，且不能少于 5 条。

```text
负面锐评：
- 最大问题：
- 可能划走点：
- 可能不转化点：
- 信任不足点：
- 复刻翻车点：
- 不适合的产品/人群：
```

要求：

- 负面评价必须具体到结构、镜头、话术、卖点或转化逻辑。
- 不能写“节奏可以优化”“内容可以更好”这类空话。

### 9. 可复用脚本模板

```text
适合复用的产品：

复用前提：

脚本骨架：
1. 开头 0-3 秒：
2. 中段证明：
3. 卖点展开：
4. 信任补强：
5. CTA 收口：

- 产品：
- 痛点：
- 场景：
- 视觉动作：
- 价格/优惠：
- CTA：
```

要求：

- 必须说明原素材里哪些结构可以保留。
- 必须说明换产品时哪些元素不能照搬。

### 10. 优化建议

按优先级输出：

```text
优先改 1：
- 问题：
- 怎么改：
- 预期提升：

优先改 2：
- 问题：
- 怎么改：
- 预期提升：

优先改 3：
- 问题：
- 怎么改：
- 预期提升：
```

要求：

- 优化建议必须能被编导、剪辑或投手直接执行。
- 不能只写“加强前 3 秒”“提高转化率”，必须写成具体动作。

### 11. 可直接改写的 TikTok 脚本方向

必须输出 3 个方向：

```text
改写方向 1：保留原结构，强化成交
适合目标：
改写开头：
中段怎么拍：
结尾 CTA：

改写方向 2：换成更强 Hook
适合目标：
改写开头：
中段怎么拍：
结尾 CTA：

改写方向 3：迁移到其他产品
适合产品：
改写开头：
中段怎么拍：
结尾 CTA：
```

要求：

- 三个方向不能只是换说法，必须有不同策略。
- 每个方向都要能直接指导下一条视频拍摄。

### 12. 最终评级

按 1-5 分输出：

```text
停留能力：
信任能力：
成交能力：
复刻能力：
整体价值：

总评：
这条素材最值得学的是……
最不能盲目抄的是……
```

## 输出要求

- 用中文分析。
- 偏实战，不做空泛总结。
- 必须指出“这条视频靠什么卖”。
- 必须指出“这条视频哪里不行”。
- 必须区分流量逻辑、信任逻辑、成交逻辑。
- 如果没有强成交逻辑，要明确说它只适合顶部漏斗或种草。
- 如果没有明确产品，也要分析它可能适合承接什么产品。
- 不要强行套固定模板；先识别类型，再选择拆法。
- 负面评价要具体，不能只说“还可以优化”。
- 所有判断都尽量绑定证据；没有证据时写“未观察到”。

## 快速示例

### 短裤优惠视频

```text
主类型：价格优惠型带货
辅助类型：中部漏斗顾虑处理型、实用卖点展示型
漏斗阶段：中部漏斗偏底部
核心逻辑：负面钩子 + 套装价格优势 + 实用卖点 + 尺码顾虑处理 + 夏季促销 CTA
成交强度评分：4/5
复刻风险等级：中
负面锐评：太依赖强优惠；如果没有真实价格优势，结构会变标题党。
```

### 粉色毛绒玩偶街访视频

```text
主类型：街访/情景采访型带货
辅助类型：角色设定/拟人化型、情绪价值种草型
漏斗阶段：顶部漏斗
核心逻辑：奇怪提问 + 产品身份梗 + 可爱近景 + 随身携带场景 + 社交话题
成交强度评分：2/5
复刻风险等级：高
负面锐评：成交逻辑弱，用户可能只记住梗，不知道产品怎么买；复刻依赖演员自然反应。
```

## 最终判断标准

一条好的解析必须让操盘手知道：

```text
这条素材为什么有人看？
为什么有人信？
为什么有人想买？
哪里会失效？
哪里不能盲目复刻？
能复制到什么产品？
优化时先改哪里？
下一条素材怎么拍？
```
